# Stock & Cryptocurrency Market Analysis Dashboard

An interactive Power BI dashboard for analyzing stock and cryptocurrency market performance, investor behavior, risk profiling, and portfolio tracking — built as an end-to-end financial analytics solution.

## Tech Stack
- **Power BI** — data modeling & report design
- **DAX** — calculated measures and KPIs
- **Power Query (M)** — data cleaning and transformation

## Overview
This dashboard brings together stock and crypto market data into a single, navigable report with a dark-themed, polished UI. It covers performance tracking, risk assessment, investor insights, and portfolio analysis across both asset classes.

## Report Pages

| Page | What it covers |
|---|---|
| **Home** | Navigation hub with KPI summary cards and buttons to all sections |
| **Stock Analysis** | Top 10 best/worst performing stocks, price trend line chart, performance comparisons across time periods |
| **Crypto Analysis** | Top performing cryptocurrencies, price trends, and comparative performance charts |
| **Risk Profile** | Daily volatility %, drawdown metrics, and high/low risk classification |
| **Investor Analysis** | Total assets breakdown, top investors, and investment trend combo chart |
| **Portfolio Analysis (Stock)** | Time-series portfolio value tracking with dynamic slicers |
| **Portfolio Analysis (Crypto)** | Time-series portfolio value tracking with dynamic slicers |
| **Get Details** | Drill-through table for granular record-level detail |

## Key Features
- **KPI Cards, Bar & Line Charts** — quickly identify top and worst performing assets and visualize price trends
- **Risk Profiling** — daily volatility and drawdown metrics to assess asset/portfolio risk
- **Portfolio Tracking** — time-series analysis with dynamic slicers to monitor performance over custom periods
- **Drill-Through Navigation** — a dedicated Get Details page for record-level exploration
- **Custom Visuals** — image carousel and gallery visuals for enhanced presentation
- **Dark-Themed UI** — custom navigation buttons and consistent visual design across all pages

## Skills Demonstrated
- Data modeling and DAX measure creation for financial metrics (volatility, drawdown, performance ranking)
- Power Query transformations for cleaning and shaping market data
- Report UX design: navigation buttons, drill-through, bookmarks, and custom visuals
- Comparative and time-series analysis across two asset classes (stocks and crypto)
